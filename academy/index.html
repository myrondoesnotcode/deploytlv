01 / See it happen

From a few sentences to a live URL

This is Academy 101, start to finish, on one small project: a website for a dog. The quotes are the actual prompts that built it.

  1. Step_01 / Describe itA few sentences, no code

    “I want to make a website for Uzi. It needs to be a pet counter. We want there to be a button that says Pet Uzi… Every time that somebody presses it, it goes up… We want it to go live on Github Pages.”

  2. Step_02 / Push backThen feedback, in plain English

    “Can you make the UI slightly more fun and modern.”

    “It’s not centered on the computer and not centered on the phone.”

  3. Step_03 / Ship itA URL on your phone

    Claude Code puts it live on GitHub Pages. Open it on your phone, send it to anyone.

06 / FAQ

Before you book

Q_01Do I need coding experience?

No. That is who the class is for. The AI writes the code; you learn how to direct it and how to get it online.

Q_02Do I need an idea?

No. Bring one if you have one. If not, you start from one of our starter projects and we help you make it yours during the build.

Q_03What do I leave with?

A finished project on a live public URL under your own account, the prompting guide that got it there, and an Academy certificate. Nothing is locked to us.

Q_04What should I bring?

A laptop and its charger, with Claude Code installed.

Q_05What software or accounts do I need?

You need Claude Code, the AI tool we build with. It comes with a Claude Pro plan or above, so sign up and install it before the session. If it isn’t working when you arrive, we fix it together in the setup block. Everything else, including GitHub, we set up with you in class.

Q_06What is the cancellation and refund policy?

Full refund if you cancel more than 48 hours before the class starts. Inside 48 hours we will move you to the next cohort.
