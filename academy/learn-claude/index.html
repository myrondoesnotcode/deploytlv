04 / FAQ

Questions

Q_01Where can I learn Claude Code in Tel Aviv, in English?

Deploy Academy teaches Claude Code hands-on, in English, at Pinsker St 11 in Tel Aviv. Academy 101 runs as a morning and an evening class: in two hours you build a website with Claude Code and put it online. Academy 201 is the four-week version where you build an app.

Q_02Do I need to know how to code to learn Claude Code?

No. The classes are for people who don’t code. Claude Code writes the code; you learn to describe what you want, test what it made and push back.

Q_03What is Claude Code?

Claude Code is Anthropic’s AI tool for building software. You describe what you want in plain English and it writes, runs and fixes the code on your computer.

Q_04What do I need before class?

A laptop with Claude Code installed. It comes with a Claude Pro plan or above, paid to Anthropic, not us. If it isn’t working when you arrive, we fix it together at the start of class.

Q_05Is it taught in English?

Yes. Every Deploy Academy class is taught in English, in person in Tel Aviv. You don’t need any Hebrew.

Q_06Can my company book a private Claude Code session?

Yes. We run the same classes privately for teams, on your own projects. Message us or email hello@deploytlv.com and we will send a proposal.
