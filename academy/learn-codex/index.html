04 / FAQ

Questions

Q_01Where can I learn OpenAI Codex in Tel Aviv, in English?

Deploy Academy 101 is taught in English at Pinsker St 11 in Tel Aviv, every Wednesday evening, and you can take it with Codex. In two hours you build a website with Codex and put it online.

Q_02Is it the same class as the Claude Code one?

Yes. The workflow is the same with either tool: describe it, test it, push back, ship it. Bring whichever you already pay for and you build with that.

Q_03Claude Code or Codex: which should I use?

Whichever you already have. Codex comes with a ChatGPT plan such as Plus; Claude Code comes with a Claude Pro plan or above. If you have neither, either one works for the class.

Q_04Do I need to know how to code?

No. Codex writes the code; you learn to direct it and get the result online.

Q_05What do I need before class?

A laptop with Codex set up and signed in to your ChatGPT account. If it isn’t working when you arrive, we fix it together at the start of class.

Q_06Is it taught in English?

Yes. Every Deploy Academy class is taught in English, in person in Tel Aviv. You don’t need any Hebrew.
